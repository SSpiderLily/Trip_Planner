### 试运行流程

1. 讨论时及时把明确结论写入需求章节；假设和未决项单独注明。
2. 需求确认后补充方案和任务。已有明确授权的范围不重复提问，新增实质性取舍才返回用户。
3. LOW 方案自动推进；MEDIUM/HIGH 方案待人工确认。本轮仅新增可逆的试跑记录和历史说明，风险 LOW。
4. 完成任务后按 AC 核对证据。自动验证不能代替最终人工验收。
5. 在同一文件维护阶段、待处理项和确认记录；恢复会话先读该文件，再核对代码或文档现状。
