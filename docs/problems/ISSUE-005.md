#### 目标与原因

新版首页与品牌视觉只存在于独立工作树，当前 VS Code 打开的项目仍显示旧页面。当前分支同时包含任务轮询、到离站地点、每日路线编辑和观测功能，不能直接覆盖这些交互。

#### 取舍与实现位置

- 保留当前分支的表单模型、任务提交与轮询、地点搜索，以及 v2/v3 路线结果组件；只替换首页页面结构和旧视觉。
- 合并品牌导航、主视觉、色彩与响应式样式，结果页在现有编辑组件上增补同一视觉语言。
- 失败原因在首页表单内持续可见，任务观测入口仍保留。

#### 验证记录

前端 `vue-tsc --noEmit` 与 Vite 生产构建通过。浏览器检查桌面及 390/375/320 像素手机页面，首页无横向溢出；窄屏日期与时间面板完整可见。原有任务轮询、地点搜索、可编辑路线与观测入口保留。未以真实模型和高德服务执行完整行程生成；原有用户工作区未覆盖；2026-10-02 已合入本地 main，待用户本地启动验收后推送。构建仍提示初始 JS 包超过 500 kB。
