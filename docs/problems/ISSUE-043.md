# ISSUE-043：天气 Span 类型不合法导致观测记录丢失

- 整理日期：2026-10-11
- 记录状态：已定位，尚未修复

weather记录使用service类型，但SQLite spans.operation_type不允许该值。临时库复现显示父记录与子工具记录丢失，任务标记observation_incomplete。

## 2. 排查过程与原因判断

只读对照历史任务、观测和已记载的专项复现。已确认条件与缺失证据分别列出，未保存的模型回答和供应商错误不能从摘要重建。

## 3. 尝试方案与方案结果

本轮仅定位并保留缺口，没有可靠修复证据。最新无超时任务仍标记观测不完整，25次模型调用和276956个已报告Token不是完整总量。

## 4. 解决结果与验证边界

已实施观测类型修正；离线验证通过，真实服务验证待重启后执行。具体执行事实和后续状态维护在下方Change入口。

## 5. 经验总结
