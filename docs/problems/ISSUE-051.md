# ISSUE-051：取消失败新增后仍重试且改变排序

- 整理日期：2026-10-11
- 状态：v3历史修复；证据来自CHG-002集成记录，本次未重跑。

## 1. 问题描述

待提交新增被删除后仍留在重试队列，折叠操作又可能改变其他活动排序。

## 2. 排查过程与原因判断

原调试记录：失败新增再删除不能继续重试该新增；折叠未提交操作时还须补偿排序，否则移除临时景点会改变其他景点最终顺序。

该记录说明已发现条件和修正方法。未保存的逐步排查或失败实验不补造。

## 3. 尝试方案与方案结果

取消未提交新增并补偿最终排序。 已包含在v3历史集成验证范围；未单独记录本问题的完整测试计数。

## 4. 解决结果与验证边界

后端83项、前端操作队列7项及相应浏览器/导出历史验证的完整证据见[集成验证](ISSUE-004.md)。这些是组合验证，不能全部算作本问题的专项测试。本次只整理文档；v4现行实现以[README](../../README.md)为准。

## 5. 经验总结
