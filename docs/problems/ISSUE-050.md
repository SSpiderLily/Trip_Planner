# ISSUE-050：长图分页遗漏长文本或显示旧时刻

- 整理日期：2026-10-11
- 状态：v3历史修复；证据来自CHG-002集成记录，本次未重跑。

## 1. 问题描述

拆散节点后继续用原页面选择器，长提示可能遗漏；选择器也可能先命中短地址。

## 2. 排查过程与原因判断

原调试记录：导出分页不能重新按原页面选择器解析已经拆散的节点，否则可能遗漏长提示；按保留的内容块分页并校验尺寸。38,000字压力测试还发现选择器先命中短地址、未拆长简介，改为选择最长文本块；更新失败或进行中时，同时隐藏旧活动时刻。

该记录说明已发现条件和修正方法。未保存的逐步排查或失败实验不补造。

## 3. 尝试方案与方案结果

按内容块分页，选最长文本切分，待更新或失败日隐藏旧时刻。 已包含在v3历史集成验证范围；未单独记录本问题的完整测试计数。

## 4. 解决结果与验证边界

后端83项、前端操作队列7项及相应浏览器/导出历史验证的完整证据见[集成验证](ISSUE-004.md)。这些是组合验证，不能全部算作本问题的专项测试。本次只整理文档；v4现行实现以[README](../../README.md)为准。

## 5. 经验总结

验证导出应检查实际图片和文本拼接，不能仅验证下载按钮。
