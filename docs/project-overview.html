哪些限制需要保留在理解中？

当前服务为单进程、单活动规划。局部编辑没有服务端持久化或多设备同步，签名在服务进程重启后失效，需重新载入原行程。地图展示地点顺序，不代表实际道路导航。费用缺失不能解释为零费用；生成完成不代表全部安排无冲突。前端历史构建仍有主包超过 500 kB 提示。

文档之间存在什么状态差异？

AGENTS.md 的部分结构与测试说明较早；目前已有后端 unittest、前端编辑测试与独立观测页。较早旅行需求中的费用和交通策略，以 CONTEXT.md、CHG-002 和当前代码为准。CHG-001 工作流试运行仍为 ACCEPTANCE / WAITING_HUMAN；CHG-002 标记 ACCEPTED。文档里“待推送”的历史描述已被本次成功推送任务分支的事实更新，但 GitHub main 合并与服务器部署未发生。
